# LEDニュースティッカー

昔の MSN ニュースティッカーのような、黒背景に LED ドットでニュースを流す Electron アプリです。

- 1行目: ニュースのタイトル（オレンジLED・固定）
- 2行目: そのニュースの内容（緑LED・右から左へゆっくり流れる）
- 本文が流れ切ると次のニュースへ。最後まで行ったら最初に戻ります

## 起動方法

```bash
npm install
npm start
```

## 操作

- ドラッグ: 上下に移動（横幅は常に画面いっぱい。マウスごと別のモニターへ持っていくとそのモニターの幅に合わせます。位置は次回起動時も保持）
  - `reserveScreenSpace` が `true` のときは、離した位置に近いほうの端（画面の上端か下端）にくっつき、その部分を他のウィンドウが使わないように確保します（タスクバーと同じしくみ）
- ダブルクリック: 表示中ニュースの記事をブラウザで開く
- 右クリック / タスクトレイ: 記事を開く、次のニュースへ、一時停止、再読み込み、設定ファイルを開く、ログイン時に起動、終了

## 表示するニュース

このフォルダ（`newsDir`）にある `.md` のうち、日付で始まるファイル名（例: `20260923_today_news.md`）の一番新しいものを表示します。`README.md` は対象外です。

md の書き方:

```markdown
## 1. タイトル
本文（複数行でもOK。1つにつなげて流します）
[記事リンク](https://...)
```

md を追加・更新すると自動で読み込み直します。

## 設定（config.json）

保存すると起動中のティッカーにすぐ反映されます。

| 項目 | 意味 |
| --- | --- |
| `scrollSpeed` | 流れる速さ（1秒あたりのドット数。大きいほど速い。1文字 ≒ `dotRows` ドット） |
| `fontSize` | 文字の高さ(px)。ウィンドウの縦サイズはこれに合わせて自動で変わります |
| `titleHoldSeconds` | タイトルを出してから本文が流れ始めるまでの秒数 |
| `itemIntervalSeconds` | 本文が流れ切ってから次のニュースに切り替わるまでの秒数 |
| `newsDir` / `newsFile` | ニュースを探すフォルダ / 表示するファイルを固定したいとき |
| `dotRows` | 1行の縦ドット数（16 で昔の電光掲示板風。増やすと文字が細かくなる） |
| `dotFill` | ドットの大きさ（ドット間隔に対する割合） |
| `lineGapDots` / `paddingDots` | 行間 / 余白（ドット数） |
| `showUnlitDots` | 消灯ドットをうっすら表示するか |
| `glow` | LED のにじみ（0 で無効） |
| `backgroundOpacity` | 背景の不透明度（1 で真っ黒、0 で完全に透明。消灯ドットも同じ濃さで透けます） |
| `fontFamily` / `fontWeight` / `dotThreshold` | ドット化する元フォント / 太さ / しきい値（小さいほど太る） |
| `colors` | `title`（1行目）、`body`（2行目）、`unlit`（消灯ドット）、`background` |
| `alwaysOnTop` | 常に最前面に表示するか |
| `reserveScreenSpace` | 画面の上端/下端をティッカー用に確保するか（Windows のみ）。`true` だと他のウィンドウを最大化してもティッカーの部分を避けます |

ウィンドウの横幅は常に画面（タスクバーを除く作業領域）いっぱいです。タイトルが画面幅より長いときは右端で切れます。
